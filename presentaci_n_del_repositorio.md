# CardioPrev: Nutrición Inteligente ❤️🥗

Aplicación web clínica diseñada para generar recomendaciones nutricionales personalizadas para la prevención y el control de la **Cardiopatía Isquémica**. 

Esta herramienta automatiza el cálculo de requerimientos energéticos y adapta menús sugeridos basándose en variables antropométricas, factores de actividad y comorbilidades (como Hipertensión y Diabetes Tipo 2), utilizando referencias clínicas internacionales.

## 📱 Características
* **Cálculo Metabólico:** Utiliza la ecuación de Mifflin-St Jeor para estimar el Gasto Energético Basal (GEB) y el Requerimiento Energético Total (RET).
* **Adaptación Clínica:** Ajusta el requerimiento calórico basado en el Índice de Masa Corporal (IMC) para objetivos de mantenimiento, pérdida segura de peso o recuperación.
* **Menú Inteligente:** Sugiere desayunos, comidas y cenas con porciones en medidas caseras.
* **Filtros de Seguridad:** Permite excluir alérgenos (lácteos, gluten, nueces, pescados) y seleccionar preferencias (Omnívoro, Vegetariano, Vegano).
* **Alertas Clínicas:** Detecta casos fuera de rango (como desnutrición severa u obesidad grado III) y emite alertas para buscar atención médica presencial.
* **Responsive Design:** Interfaz adaptativa que funciona perfectamente en computadoras, tabletas y teléfonos móviles.

## 📚 Referencias Clínicas
El motor de toma de decisiones de CardioPrev está respaldado por:
1. **American Heart Association (AHA, 2021):** *Dietary Guidance to Improve Cardiovascular Health*.
2. **European Society of Cardiology (ESC, 2021):** *Guidelines on cardiovascular disease prevention in clinical practice*.
3. **IMSS / Secretaría de Salud de México (2011):** *Guía de Práctica Clínica: Abordaje de la Rehabilitación Cardiaca en Cardiopatía Isquémica*.

## 🚀 Despliegue en GitHub Pages
Este proyecto es un "Single Page Application" (SPA) estático. No requiere bases de datos ni backend, por lo que es ideal para alojarse gratuitamente en GitHub Pages.

1. Haz un fork o sube el archivo `index.html` a un repositorio nuevo en GitHub.
2. Ve a la pestaña **Settings** (Configuración) del repositorio.
3. En el menú lateral izquierdo, selecciona **Pages**.
4. En **Source** (Origen), selecciona `Deploy from a branch`.
5. Selecciona la rama `main` y la carpeta `/(root)` y dale a **Save** (Guardar).
6. ¡En un par de minutos, tu aplicación estará en vivo y lista para compartirse mediante un enlace URL!
